# 🏥 AcuMedica – Medical Performance Dashboard

**An Interactive Power BI Dashboard for Hospital Performance, Patient Recovery & Healthcare Analytics**

AcuMedica is an interactive healthcare analytics project developed using **Microsoft Power BI** to evaluate hospital operations, patient outcomes, treatment effectiveness, and healthcare costs.

The dashboard transforms simulated healthcare data into meaningful visual insights, enabling healthcare professionals, analysts, and decision-makers to monitor hospital performance, evaluate recovery trends, compare treatment outcomes, and identify opportunities to improve healthcare delivery.

## 🎯 Project Overview

Healthcare organizations generate large volumes of operational and clinical data. Analyzing this information effectively is essential for understanding patient outcomes, improving treatment efficiency, and optimizing hospital resources.

**AcuMedica** addresses this challenge through an interactive Power BI dashboard that provides insights into:

- Hospital performance and patient distribution.
- Patient recovery rates and treatment effectiveness.
- Healthcare costs across different treatment categories.
- Patient demographics, including age groups and gender.
- Monthly and quarterly patient trends.
- Doctor-level recovery performance.

The dashboard uses interactive visualizations, calculated KPIs, and time-based analysis to simplify complex healthcare data and support data-driven decision-making.

## 🚀 Project Objectives

The primary objectives of AcuMedica are to:

1. **Benchmark Hospital Performance:** Compare hospitals using patient volume, recovery ratings, and operational KPIs.
2. **Evaluate Treatment Effectiveness:** Analyze recovery outcomes across different treatment types.
3. **Analyze Patient Demographics:** Identify trends across age groups and gender.
4. **Monitor Healthcare Costs:** Understand treatment expenses and identify cost-effective treatment approaches.
5. **Track Patient Trends:** Analyze monthly and quarterly patient activity and diagnosis patterns.
6. **Support Healthcare Decisions:** Translate analytical findings into recommendations for improving healthcare delivery.

## 💡 Key Business Insights

The analysis reveals several important patterns within the simulated healthcare dataset.

| Category | Key Finding |
|---|---|
| Hospital Performance | Green Valley Medical Center handled 28.5% of total patients. |
| Most Common Diagnosis | Asthma in Adults accounted for over 10.9% of diagnoses. |
| Patient Demographics | Adults represented the most affected age group. |
| Treatment Effectiveness | Counseling and Medication demonstrated high recovery rates with relatively low costs. |
| Doctor Performance | Barbara Jackson and Mary Jones achieved recovery ratings of 10.0. |
| Patient Trends | Monthly trends showed consistent patient flow with slight seasonal variations. |

### Business Recommendations

Based on the observed patterns, healthcare organizations could consider:

- Reviewing operational capacity at hospitals with higher patient volumes.
- Evaluating treatment approaches associated with stronger recovery outcomes.
- Assessing cost-effective treatment options without compromising patient care.
- Using demographic trends to support targeted healthcare planning.
- Monitoring doctor-level performance to identify effective clinical practices.
- Leveraging monthly and quarterly trends for resource allocation.

*These insights are based on simulated healthcare data and should be treated as analytical observations rather than validated clinical findings.*

## ⚙️ Getting Started

Follow these steps to explore the dashboard locally.

### Prerequisites

- Microsoft Power BI Desktop.
- Access to the AcuMedica project repository.
- Underlying dataset, if required by the Power BI file.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/SarthakBora12/AcuMedica-Medical-Performance-Dashboard.git
```

**2. Navigate to the project directory**

```bash
cd AcuMedica-Medical-Performance-Dashboard
```

**3. Open the Power BI dashboard**

Launch `AcuMedica_Dashboard.pbix` using Microsoft Power BI Desktop.

**4. Explore the dashboard**

Use the available interactive slicers, filters, and visualizations to analyze hospital performance, treatment outcomes, patient demographics, and healthcare trends.
